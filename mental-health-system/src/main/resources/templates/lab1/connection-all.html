Описание методов:
Метод 1: DriverManager

Базовый JDBC-подход. Параметры подключения задаются непосредственно в коде. Требует ручного управления ресурсами (закрытие соединения).

Метод 2: PGSimpleDataSource

Специализированный класс для PostgreSQL. Параметры задаются через сеттеры. Поддерживает пул соединений и более гибкую настройку.

Метод 3: Spring DataSource

Внедряется через конструктор. Конфигурируется Spring Boot на основе application.properties. Наиболее предпочтительный способ в Spring-приложениях.
