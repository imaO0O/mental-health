Лабораторная работа №3

Вызов хранимых процедур и функций PostgreSQL из Java через JdbcTemplate (аналог SqlCommand/SqlDataAdapter в C#). Тематика: тесты, протоколы тестирования, психологи.

  • 1. Снизить баллы на N%
  • 2. Добавить тест
  • 3. Удалить протоколы
  • 4. Удалить тест (коды)
  • 5. Сумма прохождений
  • 6. CRUD психологов

Задание 1. Массовое снижение баллов на N%

Что делает: у всех существующих протоколов тестирования уменьшает итоговый балл на заданный процент. Моделирует ситуацию «после психотерапевтической программы у студентов снизился уровень стресса».

Аналог из учебника: «Снизить цены всех товаров на 20 %».

Что вызывается: процедура sp_lab3_decrease_scores(p_percent) через jdbc.update("CALL ...", percent).

Параметр
Например, ввод 20 означает: новый балл = старый × 0.8.

Задание 4. Удалить тест с возвратом кода ошибки

Что делает: пытается удалить тест по шифру. Возвращает целое число — код результата (вместо бросания исключения):

  • 0  тест успешно удалён;
  • 1  нельзя удалить — есть зависимые протоколы;
  • 2  теста с таким шифром нет.

Что вызывается: функция fn_lab3_delete_test(p_test_code) через SELECT fn_lab3_delete_test(?).

Параметр
Код возврата: 0

Задание 6. CRUD по таблице психологов

Что делает: просмотр / добавление / изменение / удаление записей в таблице psychologists прямо в табличном виде — аналог SqlDataAdapter + DataGridView в C#.

Что вызывается:

  • добавление — обычный INSERT через JdbcTemplate (создаётся учётная запись + запись психолога);
  • изменение — процедура sp_lab3_psychologist_update(...);
  • удаление — DELETE по табельному номеру.
➕ Добавить психолога
При добавлении создаётся учётная запись с логином psy_<табельный №> и паролем psychologist123.
