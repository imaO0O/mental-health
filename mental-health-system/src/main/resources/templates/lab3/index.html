Лабораторная работа №3

Хранимые процедуры PostgreSQL, вызываемые из Java через JdbcTemplate (аналог SqlCommand и SqlDataAdapter в C#). Тематика — мониторинг ментального здоровья: «товары» → тесты, «поставки» → результаты тестов, «поставщики» → психологи.

  • 1. Снизить баллы на N%
  • 2. Добавить тест
  • 3. Удалить результаты
  • 4. Удалить тест (коды ошибок)
  • 5. Сумма прохождений
  • 6. CRUD психологов

1. sp_lab3_decrease_scores(p_percent)

Снижает total_score у всех результатов на заданный процент (моделирует положительный эффект психотерапевтической программы — аналог «уменьшить цену всех товаров на 20%»).

📋 Снимок ДО выполнения
✅ Снимок ПОСЛЕ выполнения (текущее содержимое test_results)

2. sp_lab3_add_test(p_test_code, p_name, p_description, p_instructions)

Добавляет новый психологический тест.

📋 Снимок ДО
✅ Снимок ПОСЛЕ (таблица tests)

3. sp_lab3_delete_protocols(p_student_login, p_test_code)

Удаляет протоколы тестирования заданного студента по заданному тесту (аналог «удалить поставки заданного поставщика и товара»).

📋 Снимок ДО
✅ Снимок ПОСЛЕ

4. fn_lab3_delete_test(p_test_code) · возвращает код 0/1/2

  • 1 — удаление невозможно: есть связанные записи (протоколы тестирования);
  • 2 — теста с таким шифром нет.
