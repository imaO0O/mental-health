Навигационный подход (без SQL-запросов): операции выполняются через репозитории Spring Data JPA и обход связей сущностей. 4. Уменьшать на 10% в цикле, пока среднее ≥ порога

На каждой итерации применяется коэффициент 0.9 ко всем total_score через JPA. Цикл останавливается, когда среднее становится меньше указанного порога или достигнут лимит итераций.

ℹ Как протестировать: чтобы цикл выполнил хотя бы одну итерацию, порог должен быть меньше текущего среднего. Если поставить порог больше — цикл сразу выйдет (0 итераций).

Текущее среднее значение баллов: 0.00 → поставьте порог, например, 0.0 и нажмите «Запустить цикл».
