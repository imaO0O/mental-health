# ER-диаграммы базы данных «Мониторинг ментального здоровья»

Папка содержит исходники концептуальной и логической модели данных,
оформленные в стиле, аналогичном существующей пояснительной записке
(`PZ_mental_health.docx`, рисунки 2 и 3).

## Файлы

| Файл | Что внутри | Чем открывать |
|---|---|---|
| `conceptual.puml` | концептуальная модель (Чен-подобная, стилизованная цветами) | PlantUML |
| `conceptual.drawio` | концептуальная модель в **строгой нотации Чена** (ромбы, овалы) | [diagrams.net](https://app.diagrams.net) / drawio desktop |
| `conceptual.png` | готовая PNG-картинка (PlantUML) | любой просмотрщик |
| `logical.puml` | логическая (реляционная) модель — 16 сущностей с PK/FK | PlantUML |
| `logical.png` | готовая PNG-картинка (PlantUML) | любой просмотрщик |
| `render.ps1` | PowerShell-скрипт повторного рендера PUML → PNG | PowerShell |

## Как пересобрать PNG из PUML

В PowerShell из корня проекта:
```powershell
.\diagrams\render.ps1
```

Скрипт использует `tools\plantuml.jar` (уже скачан, ~22 МБ) и Java 22.

## Как отредактировать концептуальную модель

1. Откройте https://app.diagrams.net (или установите drawio desktop).
2. «File → Open from → Device» → выберите `conceptual.drawio`.
3. Подвиньте элементы, добавьте/удалите связи — это обычное визуальное редактирование.
4. «File → Export as → PNG…» → сохраните `conceptual.png`.

## Как вставить в PZ_mental_health.docx

1. В Word откройте документ.
2. Выделите старую картинку (Рисунок 2 или 3) → правый клик → **Изменить рисунок → Из файла…**
3. Выберите соответствующий `.png` из этой папки.
4. Подпись «Рисунок 2 — …» / «Рисунок 3 — …» остаётся как есть.

## Соответствие стилю существующего ПЗ

| Элемент в PZ (Рис. 2 — концептуальная) | Здесь |
|---|---|
| Прямоугольники — сущности | белые прямоугольники |
| Ромбы — связи | жёлтые прямоугольники (PUML) / настоящие ромбы (drawio) |
| Овалы — атрибуты | светло-голубые прямоугольники (PUML) / настоящие овалы (drawio) |
| Кардинальности 1, M, N, L | подписи на рёбрах |

| Элемент в PZ (Рис. 3 — логическая) | Здесь |
|---|---|
| Таблицы с PK/FK маркерами | `entity { ... }` блоки PlantUML |
| Подчёркнутые ключи | `<u>...</u>` в PUML |
| Линии 1 — N | `\|\|--o{` в PUML с подписью «1..N» |

## Регенерация при изменении БД

Если структура БД меняется ([schema.sql](../mental-health-system/src/main/resources/schema.sql)
или JPA-сущности в `mental-health-system/src/main/java/.../model/`):

1. Отредактируйте соответствующий `.puml` файл.
2. Запустите `render.ps1`.
3. Замените картинку в `.docx` (или повторно экспортируйте из `.drawio`).
